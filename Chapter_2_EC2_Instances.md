#### 1. There are four types of AMIs:
- Amazon Quick Start
- AWS Marketplace
- Community
- Private

#### 2. A particular AMI will be available only in a single region
#### 3. The softwares in an AMI are billed according to the licence. 
#### 4. If you are using an instance and you need to change the type:
- Stop it
- Edit the instance type
- Start it back again
